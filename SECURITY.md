# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.2.x   | yes       |

Zeppelin is pre-1.0; only the latest release receives security fixes.

## Reporting a Vulnerability

Report vulnerabilities privately via
[GitHub Security Advisories](https://github.com/zepdb/zeppelin/security/advisories/new)
or by email to ghatage@gmail.com. Do not open public issues for security
reports.

You should receive an acknowledgement within 7 days.
